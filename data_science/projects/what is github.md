   1. github is a product of microsoft
   2. github is open source 
   3. github is create a repository systems to upload data | shared data with anyone 
   4. github is used to create to make a clone of repository
   5. github is shared data in two way **public** or **private**
   6. github is used to push data | commit data | fetch data | rollback data etc


# How to create account and repository and upload data via commands on github 


1. create an account on github 
2. login with your account 
3. create an repository on github.com
4. download an github software i.e called gitBash to upload data  via git commands 
5. add github in VS code to upload data via VS code IDE
6. **github commands**

**commands are**

1. git init
2. git add .
3. git commit -m '25-08-2026 all data uploaded'
4. git remote add origin github links
5. git push -u origin master

**how to clone a repository**

1. git clone **paste your github repository links**
